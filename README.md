# Bspline-data

B 样条曲面重建与曲线拟合相关的实验数据集，包含两个子数据集：`3D_scatter_points`（散乱三维数据点曲面重建）和 `ESC_curve`（极端采样曲线数据点）。

## 目录结构

```
Bspline-data/
├── 3D_scatter_points/     # 散乱三维数据点曲面重建数据集
│   ├── realworld/          # 真实数据
│   └── synthetic/          # 合成数据
└── ESC_curve/             # 极端采样曲线数据集
    └── figure/             # 曲线可视化图
```

## 3D_scatter_points — 散乱三维数据点曲面重建数据集

用于从散乱三维数据点重建参数曲面的基准数据集，分为真实数据与合成数据两部分。

### realworld/（真实数据）

| 文件 | 说明 |
|------|------|
| `hand.obj` | 手部模型三角网格（约 4.9 MB） |
| `tri_mask.obj` | 三角面片掩膜模型（约 132 KB） |

### synthetic/（合成数据）

由 `gen_irregular_data.py` 生成，共 20 组数据，围绕三个实验维度组织（详见 `manifest.json`）：

- **accuracy（精度）**：覆盖 600 / 5000 / 20000 点规模，采样方式含均匀（uniform）、聚簇（clustered）、稀疏（sparse）、特征加密（feature），含无噪与含噪（σ = 0.005）工况；
- **efficiency（效率）**：10 万 / 50 万 / 100 万点大规模聚簇采样，考察算法效率与内存扩展性；
- **dof（自由度）**：10 万点固定输入，配合推荐控制网格（10×10 ~ 66×66）与内部节点数配置，考察控制自由度与求解器扩展。

每组数据基于两类曲面真值生成：

- `peaks`：解析 MATLAB peaks(x,y) 函数；
- `bspline`：15×15 控制顶点的双三次（3×3 阶）张量积 B 样条，开均匀夹持节点向量。

每组数据由 4 个同名文件构成：

| 扩展名 | 内容 |
|--------|------|
| `.txt` | 观测散乱点，每行 `x y z`，科学计数法 |
| `.npz` | 真值（控制顶点网格、参考曲面等） |
| `.png` | 数据可视化图（半透明参考曲面 + 采样点） |
| `.json` | 元数据（点数、采样方式、噪声参数、真值定义、SHA256 校验等） |

文件命名规则：`{实验}_{曲面}_{点数}_{采样方式}_{噪声}_{seed}.{扩展名}`，
如 `acc_bspline15x15_n0005000_clustered_noise005_seed100.txt`。

采样点类型编码：内部点 = 0，边界点 = 1，角点 = 2（边界比例约 8%）。

## ESC_curve — 极端采样曲线数据点

面向极端采样条件下的曲线拟合（如自适应节点插入、控制顶点恢复）的曲线数据集，包含 4 种典型极端工况，每种工况对应一个数据文件与可视化图：

| 文件 | 工况 | 控制顶点数 |
|------|------|-----------|
| `density_jump.txt` | 密度突变：点密度沿曲线剧烈变化 | 18 |
| `extreme_density_ratio.txt` | 极端密度比：局部密/疏悬殊 | 35 |
| `multi_cluster.txt` | 多簇聚：多点簇被稀疏区段分隔 | 25 |
| `sharp_corner.txt` | 尖锐拐角：含高曲率折角 | 12 |

- 数据格式：`.txt` 文件每行两列（`x y`），为平面曲线数据点；
- `num_ctrl_pts.json`：各工况生成曲线所用的控制顶点数（真值），可用于拟合精度评估；
- `figure/`：各工况采样点与曲线的可视化图（JPG）。
